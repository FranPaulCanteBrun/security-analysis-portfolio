# Security Analysis & Cyberdefense Technical Portfolio

Repositorio centralizado de análisis técnico, auditorías de tráfico de red, investigación forense (DFIR) y resolución de incidentes tácticos.

## Estructura del Repositorio

* **`01-traffic-analysis/`**: Inspección profunda de paquetes (`.pcap`), reconstrucción de sesiones y filtrado avanzado con Wireshark y TShark.
* **`02-recon-and-enumeration/`**: Auditoría de puertos, detección de servicios y automatización de escaneos de red.
* **`03-dfir-investigations/`**: Análisis de artefactos de red y extracción forense.
* **`04-soc-operations/`**: Detección de patrones anómalos y análisis de eventos.

## Metodología de Trabajo
Cada reporte documenta:
1. Contexto táctico y objetivo de la auditoría.
2. Evidencia de red y correlación de capas OSI.
3. Comandos ejecutados, filtros y justificación técnica.
4. Causa raíz y medidas de mitigación.
